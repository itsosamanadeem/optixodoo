Purchase Control Hub
====================

Purchase Control Hub extends Odoo purchasing with stronger governance across
purchase requests, approvals, budgets, serial tracking, and master data.

Key Features
------------

* Department-based purchase request approval flow
* Multi-step purchase order approval chain
* Budget restrict, warning, and allow rules
* Automatic analytic distribution from department settings
* Vendor-wise purchase order creation from approved request lines
* Department manager activity notifications and review actions
* XLSX serial import for stock operations
* Auto-generated vendor and product codes
* Product asset tag and warranty fields

Main Benefits
-------------

* Standardize procurement approvals across departments
* Prevent overspending with configurable budget checks
* Reduce manual analytic coding on purchase lines
* Speed up inbound operations with serial import
* Improve traceability for products, vendors, and purchase documents
